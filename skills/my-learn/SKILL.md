# 项目经验召回与保存

按当前请求选择操作，完成主线任务后再处理保存。日常实现、命名、改写、状态检查和机械维护，不因可能产生经验而自动进入本流程。

## 选择操作

- 追问历史决策或故障经验：按下文召回，找到足够线索后停止。
- 调用 `$my-learn` 或明确要求保存、总结经验：读 [保存约定](references/capture.md)，从当前可见对话与已验证证据筛选候选。仅为复盘时，不读取外部会话日志补齐上下文。
- 调用 `$my-learn setup` 或要求接入项目：读 [接入流程](references/setup.md)，维护项目入口；不顺带迁移历史记忆。

## 召回

人工维护的跨 Agent 知识在 `~/.agents/memory/`；项目约定与当前事实优先查项目 `AGENTS.md`、既有文档、代码和测试。工具自动 memory 是历史线索，不替代当前权威来源。

已有摘要或本轮检索足够时直接复用。需要人工知识时，用任务关键词、精确错误或对象名限量检索全局 `INDEX.md`，只展开少量相关条目；未命中再按需扩大范围。目录或索引不存在时正常继续，不在召回阶段初始化。

复核易漂移事实，并区分已验证状态与历史记录。当前证据推翻旧条目时，在回答中说明适用边界；修订条目仍须具有保存授权。

## 写入边界

只保存稳定、有证据、未来会复用且无法从当前真相源轻易重新发现的知识。先找既有条目和正式载体，避免重复建档；没有合格候选时允许零写入。

写入遵循当前运行时的权限与更新入口。用户要求接入或保存不隐含发布、push、删除历史或修改工具生成库；已有授权覆盖具体操作时直接执行，无需重复确认。保留既有命名与格式，条目修订细节只在执行保存时读取。

项目 `AGENTS.md` 保留稳定约束与知识入口，详细调研、决策和故障经验放项目既有文档；跨项目知识写人工知识库。项目层不新建 `.agents/memory/`，也不把凭据、机器绝对路径或完整日志写入公开文件。
